# Security

## Reporting Vulnerabilities

Found a security vulnerability in Harvy? Please report it responsibly using our Tally form:

🔗 **[Report a Security Vulnerability](https://tally.so/r/o99dYP)**

All reports are reviewed by the security team within 3 business days.

## Security Policy

See [docs/SECURITY_VULNERABILITY_REPORTING.md](docs/SECURITY_VULNERABILITY_REPORTING.md) for detailed information about our vulnerability reporting process, response timeline, and guidelines.

## Scope

This reporting process applies to:
- Harvy platform codebase
- Cloudflare Workers and infrastructure
- Data collection components
- API endpoints and integrations

## Recognition

We appreciate security researchers who help improve Harvy's security! Valid, in-scope reports may be publicly acknowledged (unless you prefer to remain anonymous).
